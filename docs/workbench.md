# macOS 本机 AI 复盘工作台

本工作台在本机浏览器中运行，由 ATAS X 图表上的只读 **AI Bridge** 指标打开。
它只支持用户主动发起的 BTCUSDT（Binance Futures）Crypto Sim 复盘，不下单、
不自动记录成交，也不在平仓后自动调用模型。手动交易需要独立的模拟交易记录器。
模型服务由用户自行配置；当前实现是 **Chat Completions 兼容的文本接口**，
并未验证所有供应商或真实付费模型。安装与构建细节见 [macOS 指南](macos.md)，
验证证据与待验项目见 [验证记录](validation/2026-11-09-workbench.md)。

## 安装与打开

1. 安装可正常使用的 ATAS X、.NET 10 SDK、Python 3.12+。在项目根目录运行：

   ```bash
   bash build.sh
   # 退出 ATAS 后安装只读指标；已有同名 DLL 会先备份。
   bash build.sh --install
   bash install-workbench.sh --install
   ```

2. 在 BTCUSDT（Binance Futures）的 Crypto Sim 图表中，从**指标**列表添加
   **AI Bridge — read only** 并应用。先核对图表上的 `READ ONLY` 状态与模拟账户。
   若当前图表的指标数量受订阅限制，可改用另一张空白的同类模拟图表；
   不必删除原图指标或调整订阅。
3. 点击图表上的“打开 AI 工作台”。也可双击
   `~/Library/Application Support/ATAS AI Review/Open ATAS AI Review.command`
   手动打开；但手动打开不等于桥已连接，仍须核对首页状态。
   重复打开会复用本机后台。工作台只监听 `127.0.0.1:8770–8780`；
   行情桥使用另一个本机端口，不需要开放公网端口。

安装器为工作台创建独立 Python `.venv`，不安装网络包；MCP 客户端的 `mcp/.venv`
与工作台分开。图表按钮只读取默认状态目录中的 `installation.json`。
`--state-dir PATH` 适用于手动启动或隔离测试，不能改变图表按钮的默认查找位置。
页面启动凭证短时有效且只使用一次；页面会移除启动片段，再建立本机会话。
会话失效时，从图表按钮或启动器重新打开。
同一状态目录由后台持有进程生命周期锁。若启动器提示后台忙或暂时无响应，
等待后手动重试；不会因控制请求超时而另开一个可写后台，也不会重试模型请求。
不要删除运行中的 `instance.lock`。升级工作台代码后，先正常结束旧后台再重新打开，
并刷新已打开的页面，以启用新接口与锁保护；无需迁移 SQLite 或重新安装网络依赖。

## 自带模型服务与 Key

1. 打开“模型设置”，填写服务商提供的**完整 Base URL** 和模型名，
   例如 `https://example.com/v1` 与 `your-model`；这两个字符串只是占位示例，
   不是服务商推荐。工作台向该地址追加 `/chat/completions`，实际目标会在发送预览中显示。
2. 点击“保存目标与模式”，再输入自己的 Key 并点击“单独保存 Key”。
   “测试连接”只发送固定合成文本，不发送行情、日志或系统档案；测试仍是一次真实服务请求，
   是否计费取决于所选服务。额度不足、限流、认证失败和服务不可用会分别提示。
3. 默认 Key 只保存在**本次后台进程**的内存中；关闭浏览器标签页不会结束后台会话。
   后台退出后需重新输入。勾选后才保存到 macOS Keychain。Key 不回显，
   不存于浏览器持久存储、SQLite、URL 或工作台日志。

Key 按规范化后的**完整 Base URL** 绑定。换地址后先保存目标，再为新地址单独输入 Key；
原地址的 Key 不会随之转移。远程地址必须使用 HTTPS；HTTP 只允许明确配置的数字
loopback 地址，例如 `http://127.0.0.1:8000/v1`。工作台拒绝服务端重定向。
“删除当前地址的 Key”只作用于当前服务地址。工作台不读取 MCP 客户端的模型凭据。
设置首次载入前，保存、删除和测试操作不可用。每次操作都核对页面所见的地址、模型和
保存模式；如果另一标签页已改变共享设置，后台会拒绝本次操作，保留输入框内未保存的 Key。
点击“刷新服务设置”，核对最新目标与 Key 的归属，再点“确认当前目标与 Key 归属”后
手动操作。刷新或确认本身不保存 Key、不发送模型请求，也不会把后台目标改回旧页面的地址。

## 建立系统并分析

1. “我的系统”可填写名称、周期、setup、入场、退出、风险和练习目标，
   也可留空；下方“可编辑复盘指令”可以修改。固定的只读执行与证据边界不可编辑。
   每次保存都产生新的系统和 Prompt 版本；旧报告仍引用生成时的版本。
2. 回到“分析”，确认 ATAS 桥、图表、账户和数据年龄。选择“当前行情”或已连接日志中的
   一笔**已平仓模拟交易**，输入问题，点击“生成发送预览”。这一步只在本机采集并保存证据，
   **不会调用模型**。若改动问题或证据来源，需要重新生成预览。
3. 展开预览，核对服务目标、模型、数据质量、时间、完整证据与将发送的请求。
   点击“发送至模型”后才会把预览中的问题、系统档案、可编辑指令和证据发送到所示地址。
   发送行为可能产生费用。每份预览只能提交一次；模型任务不会自动重试。
4. 在“报告历史”查看本机保存的报告。报告保留原始证据、系统／Prompt 版本、
   请求的模型、服务端返回的实际模型（若提供有效标识）、返回的用量与质量标记；
   请求别名与实际模型分开显示。缺失或无效的实际模型保持未知，不会推算费用。
   报告文本按纯文本显示，不执行 HTML 或脚本。`[E:id]` 仅核对引用 ID 是否在证据包内，
   **不保证模型的逐句解释正确**；未知或缺少引用会标出。
5. “继续追问”只沿用该报告的旧证据，不获取新行情；最多 6 次，
   请求大小限制可能更早阻止追问。要看新数据，请重新生成预览。
   “生成修改提案”只显示原版与建议版差异；明确点击“接受并生成新版本”才修改系统。
   拒绝不修改版本。若当前版本已变化，请查看版本记录，手动合并差异或明确载入当前版本。
   重新根据旧报告生成提案也不能绕过版本冲突；未保存的草稿不会被自动覆盖。

“打开本地演示”使用明确标记的合成数据，不调用模型，也不代表实际行情或日志交易。
演示报告不能追问或生成提案。

## 可选模拟交易日志

已有独立模拟交易日志及其只读 MCP 服务时，可在安装工作台时同时传入四项现有文件／账户：

```bash
bash install-workbench.sh --install \
  --journal-python /absolute/path/to/python3 \
  --journal-script /absolute/path/to/journal-server.py \
  --journal-db /absolute/path/to/existing-journal.sqlite \
  --journal-account YOUR_SIM_ACCOUNT_ID
```

四项必须同时提供。配置只写到本机私有 `journal.json`，页面不能指定脚本、数据库或账户。
工作台只调用日志服务的固定只读查询；它不会创建、迁移或修改交易数据库。
升级安装未提供日志参数时沿用原配置；`--disable-journal` 只移除适配器配置，
不会删除原数据库。未连接时“交易日志”显示原因，行情分析仍可用。
日志列表最多显示最近查询的 50 条范围结果；仅可选择经验证的已平仓模拟交易。
历史记录不能证明当前已空仓。缺少手续费、初始风险或精确逐笔极值时保持未知，
不猜算净盈亏、R 倍数或心理状态。

## 数据与运行边界

- 新行情分析只接受只读、已连接、已激活、非真实账户的
  `BTCUSDT@BinanceFutures` Mac 指标，且本地快照与公开成交年龄均不超过 5 秒。
  缺少图表类型／周期元数据、标的或账户状态变化时停止采集。
- 一次证据包最多 131072 UTF-8 字节，模型请求最多 196608 字节；
  超限会报错，不静默删减字节。默认取最近 20 根已闭合 K 线，
  最近 2 根 Footprint 的各前 20 个成交量价位、DOM 每侧 15 档、
  200 根范围 Profile 的前 20 个成交量价位。未闭合 K 线单列，
  不计入已闭合统计；交易日志抽样最多 60 条。
- CVD 是返回窗口内的相对累计，需看会话重置位置；DOM 只是可见快照。
  各端点有各自的获取时间，不是原子市场快照。图表聚合价位不等于交易所原始逐笔报价。
  数据不足、过期、缺项或截断时以预览中的质量标记为准。
- 本机同时只执行一个模型任务，不排队；本进程最多保留 64 条可查询任务状态。
  报告历史列表显示最近 50 份。工作台只读行情／日志，但模型服务会收到用户明确提交的
  预览内容；请先阅读完整请求和服务商的数据处理条款。

## 恢复、回退与卸载

- 桥未连接或行情过期：确认模拟图表中已应用只读指标、数据连接正常，
  再点“刷新连接”并重新生成预览。旧版桥若缺少图表类型／周期元数据，需更新 Mac 指标。
- 模型请求失败、页面刷新或后台退出：先看报告历史与提案列表。
  页面刷新可恢复本进程内仍存在的任务状态；后台重启后任务状态可能不在，
  但已保存的报告／提案仍可读取。**已提交的预览不会自动再发**。
  若服务端已收到请求而后台在保存报告前退出，服务商可能已计费；
  先核对服务商请求历史，再由自己决定是否生成新预览重试。
- 系统版本冲突：先在“我的系统”查看当前版本与版本记录，手动合并草稿后确认新基准，
  或明确载入当前版本替换草稿，再保存。旧报告保留其原版本。
- 回退指标：退出 ATAS 后，按 [macOS 指南](macos.md) 中的 `.bak.*` 步骤恢复 DLL。
  卸载工作台时先结束后台进程，再移走默认状态目录的 `installation.json`、
  `Open ATAS AI Review.command`；需要时再移走专用 `.venv`。
  默认**保留** `workbench.sqlite3`、`journal.json`、报告及独立交易数据库。
  删除报告前先自行备份并确认，不把卸载启动器等同于清除个人数据。
