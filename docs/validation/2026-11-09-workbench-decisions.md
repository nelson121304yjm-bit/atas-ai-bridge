# 工作台实现取舍（2026-11-09）

以下记录实施过程中为完成已批准方案而作出的决定及其代价。

1. 沿用现有 fork 的功能分支和专用目录。用户已授权继续该项目；若出现无关修改，须保留并重新核对，不能覆盖。
2. 图表入口只读取默认安装目录；自定义状态目录用于手动启动或隔离测试。代价是自定义安装不能直接改变图表入口的查找位置，安装说明已明示。
3. 复用后台时，通过认证控制接口更新桥端口。代价是切换必须成功应用才更新运行元数据，否则保留旧目标并报错，避免静默读取旧图表。
4. 报告存储容量单独覆盖最多六次允许大小内的追问。证据包上限不用于累计回答；代价是本机报告可以比单次证据包大，但仍有容量界限。
5. 额度不足与普通限流分开提示，只解析受限的错误代码。代价是未知供应商错误可能归为通用类别，不回显原始错误正文。
6. macOS 桥增加图表类型／周期信息并升级为 0.4，以核对采集身份。代价是缺少这些信息的旧桥需要更新，不能继续生成新行情证据。
7. 未闭合 K 线从已闭合统计中排除，但单独保留形成中 K 线、CVD 和 Footprint。代价是使用者仍须阅读未闭合及窗口边界标记，不能当作最终值。
8. 可选日志使用安装器管理的私有配置，浏览器不能指定脚本、数据库或账户。代价是配置缺失或无效时关闭日志功能，但不影响其他工作台功能。
9. 提案保存到本机并提供读取恢复；接受仍需原版本匹配。代价是增加少量本地状态，以避免刷新或重启后丢失待决定的提案。
10. 最终复核发现闲置 HTTP 连接可能阻塞退出后，继续完成限定范围的关闭修复。风险是过早释放所有权或影响正在执行的任务，因此用真实连接与任务排空测试确认，再独立复核。
11. 原生入口采用英文 `AI Review`，原生工作台状态也使用英文；浏览器界面保持中文。代价是入口文字不全中文，换来已在实际 ATAS 字体与 Retina 显示上确认的可读性。
