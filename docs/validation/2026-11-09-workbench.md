## 待验与已知限制

- 图表入口目前打开本机浏览器工作台。用户已确认可以打开，但反馈按钮占用看盘位置，
  并提出改为 ATAS 内置窗口；这是下一阶段的交互改进，不把当前浏览器版本称为内置窗口。
- 已有可选模拟日志的只读适配器曾完成本机列表与已平仓交易采集检查，
  已装页面也显示日志连接和符合配置范围的已平仓交易；不在公共记录中放账户或交易内容。
- 未在 Windows 主机运行完整构建／平台测试；未验证真实付费模型、
  任何特定服务商的响应、费用、长期稳定性或真实账户使用。
- 行情桥提供的是当前模拟图表的有界快照；历史交易不能证明当前空仓。
  证据引用检查只验证 ID 是否存在，不能把模型文字自动认定为事实。

此前 **0.3.0-macos.2** 曾在单张模拟图表读取行情；该历史验收属于旧版，
不覆盖本次新增的工作台入口或 0.4 实时采集。

实施期间作出的范围与兼容性取舍见 [实现取舍记录](2026-11-09-workbench-decisions.md)。
