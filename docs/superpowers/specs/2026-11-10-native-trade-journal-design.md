# ATAS 原生交易日志接入

用户已批准：优先复用 ATAS 自带交易日志，先对账一笔已有模拟交易，再生成复盘证据。停止原生标签页排障；本轮不继续窗口开发。

## 数据与边界

已有 `AI Bridge — read only` 指标通过公开 `TradingStatisticsProvider` 读取当前图表所选模拟账户、`BTCUSDT@BinanceFutures` 的原生历史。只读取，不修改全局日志筛选器、订单、账户、注释或 Reviewed 标记。当前图表账户不明确、实盘、其他品种、已卸载时拒绝读取。不得从别的端口、账户或旧缓存猜选来源。

首版优先公开 `LoadHistoryAsync` 按当前账户/品种读取最近 7 天；请求单飞、有限等待、最多返回最新 100 条配对记录，明确范围/截断/未完成记录。若该 API 在宿主运行时不可用，报告原因；只能在明确标注“当前已加载记录，非全部历史”的情况下读取公开 Realtime 统计集合，不把回放混入实时模拟。

保留 ATAS 自身配对记录粒度和成交引用，分批平仓不擅自合成一次完整交易。价格、数量、PnL、可空手续费使用十进制字符串；盈亏标记为 ATAS 原值，不自行扣第二遍手续费、不推断净收益、币种或仓位单位。方向以明确的开仓成交方向为准。时间保留宿主原始 ISO 表示和 Kind；未知时区不强行附加 Z，不参与精确盘口关联。

行情数据桥继续只读。首版原生日志证据中的历史 Delta/DOM/初始风险/MAE/MFE 明确缺失，不将当前快照套到历史成交上。额外记录器配置和数据保留，但不再作为交易事实的默认来源。

## 工作台与 AI

工作台交易日志默认使用同一个行情桥端口的 ATAS 原生来源，显示原生配对记录、开平仓时间/价量、原生盈亏和手续费，以及加载范围/质量提示。选择一条记录可查看本地证据，不需要配置模型；已有“生成发送预览 → 明确点击分析”流程继续控制外发。账户/成交私有标识不进入模型证据；本轮不发真实模型请求。

MCP 可增加只读原生日志列表/单条证据工具，限制与工作台相同。不增加交易工具。

## 验收

- 合成测试覆盖账户/品种隔离、部分平仓、手续费缺失、未知时区、重复记录、数量精度、读取失败/超时、来源切换和卸载后的迟到结果。
- 当前 SDK 构建与实际 DLL 合约验证；Python/JS 回归。
- 备份安装，只在必要时更新既有插件。不得重启正在交易的 ATAS、重复添加指标或破坏记录器设置。
- 读取一条已有已结束模拟记录，与原生日志 UI 或本地只读原生存储核对；保存去身份验证结果，原始私有数据不入 Git。
- 原生记录进入工作台并产生证据，模型零调用。推送既有 fork 分支；不发上游 PR。
