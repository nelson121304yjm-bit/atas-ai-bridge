# ATAS 原生交易日志接入

## 2026-11-10 用户修订：零新增指标

用户明确拒绝再添加或恢复图表指标作为复盘前提。首选入口改为工作台只读读取本机 ATAS 已落盘原生日志，独立于图表、AI Bridge 端口和行情连接。下面的图表公开 API 实现保留为可选能力，不再作为默认来源或本次验收前提。

- 来源为标准 ATAS Database 目录中的 `Portfolio.cdb`、`HistoryMyTrade.cdb` 和 `MyTrade.cdb`；首版只支持经本机确认的带 Version/Entity/Columns/StartData/EndData 的 CSV 文本格式。不写入这些文件，也不读取凭据、连接配置、回放文件或其他目录。未知版本、字段、截断或读时变化必须明确失败。
- 只有 Portfolio 明确 `IsRealAccount=False` 且原生日志存在 BTCUSDT@BinanceFutures 的账户才可选。恰好一个账户可自动选择；多个时要求用户在本地工作台明确选择。账户 ID 不硬编码、不进入模型证据；不能把历史账户状态说成当前账户、当前空仓或实时状态。
- 最多读取每文件 8 MiB、10000 行；默认本机墙钟最近7天、最多100条原生配对记录。标明本地快照、文件更新时间、查询范围与截断情况，不声称完整服务器历史或实时同步。时间无时区则保持 Unspecified；空手续费保持未知。
- 原生账户/成交引用只在本地做筛选、配对和对账；选择键使用随机会话盐生成不透明标识。列表和单条 MCP 证据均采用明确字段白名单。数据变动时重新核实选择的原生行与来源，不能错误选中另一账户记录。
- 实际落盘格式核查：配对行 OpenVolume／CloseVolume 是有符号原值，负数不是坏数据。原样保存与显示，不取绝对值替代；只在与明确成交量校验时比较绝对量。不得用数量正负推断方向。价格必须非负，独立成交 MyTrade 的数量按其格式校验。共享公开 API 消费端也不得拒绝合法的有符号配对数量。
- 沿用工作台现有本地证据、Prompt版本、发送预览和明确分析操作。无模型配置时列表和本地证据可用，不接入假数据、不调用真实模型。旧桥接和记录器配置保留。
- 自定义模板／模块作为后续可选显示入口，本次不修改工作区或加模块。官方文档 `https://docs.atas.net/en/modules/custom-modules.html` 与当前安装 SDK核查记录：当前安装8.0.15.663中未找到公开 PlatformModule类型，不能声称已验证该入口。

用户已批准：优先复用 ATAS 自带交易日志，先对账一笔已有模拟交易，再生成复盘证据。停止原生标签页排障；本轮不继续窗口开发。

## 数据与边界

已有 `AI Bridge — read only` 指标通过公开 `TradingStatisticsProvider` 读取当前图表所选模拟账户、`BTCUSDT@BinanceFutures` 的原生历史。只读取，不修改全局日志筛选器、订单、账户、注释或 Reviewed 标记。当前图表账户不明确、实盘、其他品种、已卸载时拒绝读取。不得从别的端口、账户或旧缓存猜选来源。

首版优先公开 `LoadHistoryAsync` 按当前账户/品种读取最近 7 天；请求单飞、有限等待、最多返回最新 100 条配对记录，明确范围/截断/未完成记录。若该 API 在宿主运行时不可用，报告原因；只能在明确标注“当前已加载记录，非全部历史”的情况下读取公开 Realtime 统计集合，不把回放混入实时模拟。

保留 ATAS 自身配对记录粒度和成交引用，分批平仓不擅自合成一次完整交易。价格、数量、PnL、可空手续费使用十进制字符串；盈亏标记为 ATAS 原值，不自行扣第二遍手续费、不推断净收益、币种或仓位单位。方向以明确的开仓成交方向为准。时间保留宿主原始 ISO 表示和 Kind；未知时区不强行附加 Z，不参与精确盘口关联。

行情数据桥继续只读。首版原生日志证据中的历史 Delta/DOM/初始风险/MAE/MFE 明确缺失，不将当前快照套到历史成交上。额外记录器配置和数据保留，但不再作为交易事实的默认来源。

## 工作台与 AI

工作台交易日志默认使用同一个行情桥端口的 ATAS 原生来源，显示原生配对记录、开平仓时间/价量、原生盈亏和手续费，以及加载范围/质量提示。选择一条记录可查看本地证据，不需要配置模型；已有“生成发送预览 → 明确点击分析”流程继续控制外发。账户/成交私有标识不进入模型证据；本轮不发真实模型请求。

MCP 可增加只读原生日志列表/单条证据工具，限制与工作台相同。不增加交易工具。

## 验收

- 合成测试覆盖账户/品种隔离、部分平仓、手续费缺失、未知时区、重复记录、数量精度、读取失败/超时、来源切换和卸载后的迟到结果。
- 当前 SDK 构建与实际 DLL 合约验证；Python/JS 回归。
- 备份安装，只在必要时更新既有插件。不得重启正在交易的 ATAS、重复添加指标或破坏记录器设置。
- 读取一条已有已结束模拟记录，与原生日志 UI 或本地只读原生存储核对；保存去身份验证结果，原始私有数据不入 Git。
- 原生记录进入工作台并产生证据，模型零调用。推送既有 fork 分支；不发上游 PR。
